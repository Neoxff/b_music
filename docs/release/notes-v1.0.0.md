# B Music 1.0.0 — Notes de version (FR / EN)

> Statut : **brouillon** — ne pas publier tant que les gates Lean / Security / PM ne sont pas vertes.

## FR

**B Music 1.0.0** — lecteur de musique local pour Android.

### Nouveautés
- Nouveau design B Music : surfaces opaques sombres, typographie Inter, accent orange sobre.
- Animations fluides 60/120 fps (mini-player → plein écran, transitions de listes).
- Nouveau logo et icône adaptative + monochrome.
- Bibliothèque locale : titres, albums, artistes, playlists, favoris, recherche instantanée.
- Lecture en arrière-plan, notification média et contrôles d'écran de verrouillage.
- Thèmes sombre / clair, français par défaut, English inclus.

### Confidentialité
- Aucune publicité, aucun compte, aucune collecte de données.
- Aucune autorisation réseau en version fdroid : 100 % hors ligne.

### Installation
- Téléchargez `B-Music.apk`, autorisez « Installer des applications inconnues », installez.
- Vérifiez l'intégrité avec `SHA256SUMS.txt`.

## EN

**B Music 1.0.0** — local music player for Android.

### What's new
- New B Music design: dark opaque surfaces, Inter typography, restrained orange accent.
- Fluid 60/120 fps animations (mini-player → full screen, list transitions).
- New logo with adaptive + monochrome icon.
- Local library: tracks, albums, artists, playlists, favorites, instant search.
- Background playback, media notification and lockscreen controls.
- Dark / light themes, French by default, English included.

### Privacy
- No ads, no account, no data collection.
- No network permission in the fdroid build: 100% offline.

### Install
- Download `B-Music.apk`, allow "Install unknown apps", install.
- Verify integrity with `SHA256SUMS.txt`.
